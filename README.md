---

## 📖 About the Project

This website was designed as a digital farewell experience for the students of SMCS.  
It includes sections highlighting memories, messages, and the spirit of the graduating batch.

The goal of the project was to create something meaningful and interactive for the farewell while also experimenting with web development.

---

## ✨ Features

- 🎉 Dedicated farewell webpage for the graduating batch
- 🖼️ Sections for memories and messages
- 🎨 Styled layout using modern CSS
- 📱 Responsive design for different screen sizes

---

## 📌 Purpose

This project was created as a **digital farewell tribute for the graduating class of St. Mary's Convent School (SMCS)**.

It was also built as a learning experience to explore **front-end web development using HTML, CSS, and JavaScript**.
